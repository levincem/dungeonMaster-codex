//////////////////////////////////////////////////
// Name

DM1GDED

//////////////////////////////////////////////////
// What's this

This is an unofficial tool for the game Dungeon Master to produce game MOD.

DM21DED helps you to edit IMG/SND data in graphics.dat.

//////////////////////////////////////////////////
// Release

2005-02-23 (Rev.0)

//////////////////////////////////////////////////
// Requirements

Windows 95 or later
64MB ram or better
High color capable display and vga device or better

//////////////////////////////////////////////////
// Tested OS

PC/AT Japanese Windows 2000 Pro SP4

//////////////////////////////////////////////////
// Primary aim

Not yet

//////////////////////////////////////////////////
// Secondary aim

Not yet

//////////////////////////////////////////////////
// Usage (preparation)

1. Open your graphics.dat

Select menu [File]->[Open...] and open it.

2. Select map file

Select menu [Map file] and select the most possible one.
